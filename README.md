# 🩺 Дневник Диабета & Самоконтроля (РинФаст и Тресиба)

Веб-приложение для ежедневного самоконтроля сахарного диабета, учета уровня глюкозы, углеводов, Хлебных Единиц (ХЕ), калорий, доз инсулинов **РинФаст** и **Тресиба**, интерактивных графиков динамики за месяц и экспорта отчетов в PDF для лечащего врача-эндокринолога.

---

## 🚀 Быстрый запуск на сервере через Docker (Порт 4999)

### Требования
- Установленный `Docker` и `Docker Compose`

### Запуск одной командой
```bash
docker compose up -d --build
```

После этого контейнер запускается и слушает локальный порт хоста:
- **Внутри контейнера:** порт `4999`
- **На хосте:** `http://127.0.0.1:4999`

### Остановка
```bash
docker compose down
```

---

## 🌐 Настройка Nginx на сервере (домен `gluco.zduben.ru`)

Nginx на хосте проксирует запросы с домена `gluco.zduben.ru` на локальный порт `4999`.

### 1. Создайте файл конфигурации Nginx
```bash
sudo nano /etc/nginx/sites-available/gluco.zduben.ru
```

### 2. Конфигурация для получения SSL и проксирования
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name gluco.zduben.ru;

    # Для проверки Let's Encrypt / Certbot
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    # Проксирование на приложение (порт 4999)
    location / {
        proxy_pass http://127.0.0.1:4999;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 3. Активируйте сайт и проверьте Nginx
```bash
sudo ln -s /etc/nginx/sites-available/gluco.zduben.ru /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 🔒 Выпуск SSL-сертификата (Let's Encrypt / Certbot)

### Команда выпуска сертификата:
```bash
sudo certbot --nginx -d gluco.zduben.ru
```
Certbot автоматически проверит домен, выпустит SSL-сертификат и настроит HTTPS с автоматическим редиректом.

### Проверка автоматического продления сертификата:
```bash
sudo certbot renew --dry-run
```

## 📋 Табличный вид: Дневник самоконтроля

В таблице реализованы все запрошенные столбцы и автоматические алгоритмы:

1. **Дата и Время** — хронологический порядок замеров.
2. **Глюкоза (ммоль/л)** — значение сахара крови.
3. **Оценка (авто)** — рассчитывается мгновенно при вводе сахара по клинической шкале:
   - 🔴 **≤ 3.9 ммоль/л** — **Низкий** (Гипогликемия, выделяется красным).
   - 🟢 **4.0 – 9.9 ммоль/л** — **Норма** (Целевой диапазон, выделяется зеленым).
   - 🟡 **10.0 – 13.9 ммоль/л** — **Высокий** (Гипергликемия, выделяется желтым/янтарным).
   - 🟣 **> 13.9 ммоль/л** — **Очень высокий** (Выраженная гипергликемия, выделяется красным/пурпурным).
4. **Углеводы (г)** — количество съеденных граммов углеводов.
5. **ХЕ (авто)** — рассчитывается автоматически: количество углеводов делится на 12 (или настраиваемый коэффициент в настройках).
6. **РинФаст (ед)** — доза ультракороткого инсулина аспарт (на еду или коррекцию).
7. **Тресиба (ед)** — доза базального сверхдлительного инсулина деглудек (обычно ставится раз в сутки на ночь).
8. **Калории (ккал)** — энергетическая ценность приема пищи.
9. **Еда / нагрузка / комментарий** — подробное описание блюд, физических нагрузок, самочувствия.
10. **Автоматические итоги за день (футер дня)**:
    - **Средний сахар за день (авто)** — среднее арифметическое всех замеров за дату.
    - **РинФаст за день (авто)** — сумма единиц короткого инсулина за день.
    - **Тресиба за день (авто)** — сумма единиц длинного инсулина за день.
    - **Калории за день (авто)** — суммарная калорийность за сутки.
    - **ХЕ и углеводы за день (авто)** — суммарное потребление углеводов.

## 📊 Графики динамики за месяц

- **Интерактивный график уровня сахара**: полотно с замерами и **зеленым целевым коридором (4.0 – 9.9 ммоль/л)**.
- **TIR (Time in Range)**: процентное соотношение времени в норме, гипогликемии и гипергликемии (цель эндокринологов >70% в норме).
- **Распределение по времени суток**: средний сахар утром (натощак), днем, вечером и ночью.
- **Суточные дозировки инсулинов**: наглядный столбиковый график соотношения болюса (РинФаст) и базала (Тресиба).
- **Расчетный гликированный гемоглобин (HbA1c / GMI)**.

## 📄 Экспорт отчета в PDF для врача

- Вкладка **"Отчет для врача (PDF)"** формирует официальный медицинский бланк формата А4.
- Включает сводку за 7, 14, 30 дней или весь период: средняя гликемия, TIR %, расчетный HbA1c, средние суточные дозы инсулинов.
- Детализированная таблица по суткам с предотвращением разрыва дней на границе страниц (`page-break-inside: avoid`).
- Место для заключений и подписи врача.
- Кнопка **"Печать / Сохранить в PDF"** использует нативный диалог операционной системы (ПК, Android, iOS) с сохранением кристальной векторной четкости текста и корректной кодировки кириллицы.
- Возможность выгрузки в **Excel / CSV**.

## 📱 Адаптивность для ПК и Телефонов

- **На ПК**: расширенная медицинская таблица с фильтрами, сортировками и поиском.
- **На смартфоне**: оптимизированный карточный интерфейс с крупными бейджами сахара и быстрыми чипсами доз, а также плавающая кнопка **(+)** внизу экрана для быстрого добавления замера за 5 секунд.
- Переключатель между карточным и табличным видом доступен прямо из шапки.
